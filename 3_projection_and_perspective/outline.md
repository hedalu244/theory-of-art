# 投影法と遠近法

### 投影法とは
具象画の多くは、3次元空間に存在するものを2次元の画面の中に描きます。2次元の絵の中に「直接」3次元のものを収めることはできないので、3次元を何らかの方法で2次元に変換する必要があります。これはどのように変換しても構わないのですが、局所的に規則を適用するとどこかでつじつまが合わない部分が出てしまうことがあります。画面全体に対して一定の規則で変換することができると、説得力のある絵を描くことができます。このような規則的な変換方法の一つとして、投影法が存在します。

先ほど私は「具象画の多くは」は、と前置きしました。逆に言えば、もとから３次元的なものが存在しない抽象画や平面的なグラフィックデザイン、デフォルメの強いイラストにおいては、投影法のような厳密な変換を用いなくても成立します。また、3次元をそのまま3次元として扱う彫刻や3Dモデリングにおいては、投影法は必要ありません。

絵をほとんど描いたことがない人でも、「近くにあるものは大きく、遠くにあるほど小さく見える」くらいは聞いたことがあるでしょう。これはなぜでしょうか？また、定量的にどれくらい離れるとどれくらい小さく見えるのでしょうか。この疑問には透視投影を学ぶと答えることができます。

### 何に役立つか
投影法は、何かしら形に法則性がある立体の描画において特に有効です。ここでいう法則性とは、
・左右対称
・規格化された形を持っている
・平行や直角、水平や鉛直を含む
などを指します。このような形状を、美術の文脈では「幾何形体」と呼ぶことがあります。より具体的なモチーフの場合では「工業製品」と呼ぶこともあります。

『工業製品』の具体例
・家、ビル
・机、椅子、家具、文房具
・車、電車、飛行機

一方で、特に法則性のない形状、例えば自由に変形する布やクッションのような形は、3次元から2次元への変換において多少形が歪んだとしても、もともとの形状が歪んでいたのだと理解され、大きな違和感になりません。人体については、基本構造が左右対称、直立している場合に限っては肩が水平、などという程度で弱い法則性があり、投影法を応用できる場面もありますが、基本的には厳密に適用できるものではありません。このようなものの詳細は形態学にて扱います。

### 透視投影の分かりやすい性質
透視投影は視点を固定し、透明な板を置いてなぞる行為に相当する。これは、視点から出来上がった投影図を見た場合に、視野を正確に（少なくとも何がどこにどの形で見えるかという点においては）再現できることを意味する。
光の直進性から、視点を通る直線上で移動しても見える位置は変わらないから。
この性質を利用すると、トリックアート的な表現もできる。
また、モチーフをカメラで撮影した像ともおおかた一定する。

### 透視図法の代替

透視図法には代替物がいくつかある。つまり、透視図法を使わずに、立体物をできるだけ正確に描く方法。
1つは、想定でデッサンする。練習して気合で合わせる。
1つは、現物を用意してデッサンする。視点を固定し、角度を測ったりしながら気合で合わせる。練習が必要で、透視図法の知識なくてはほぼ不可能。
写真を撮ってトレースする。簡単ではある。空想上のものが書けない。
CGを使う。透視図法の知識はいらないが、勝手に超正確な透視図が出来上がるようなものなので、むしろ注意が必要。
自由変形を使う。複雑な図形の時に威力を発揮する。正確に描くには透視図法の知識が必要

これらを候補に入れ、部分的に使うことなども考えながら、楽な方法をとるのが良い。

### 透視投影の限界と絵への活かし方

このような投影法、特に「パース」は、絵を描く人の間でも特に難しいと敬遠されることが多いです。
単に苦手というだけならいいのですが、

これから学ぶ投影法での作図法は、幾何学的な図形を正確に描くための強力なツールではある。
一方で、実際に絵に描くものは必ずしも幾何学的なものばかりではなく、また正確な絵が求められているとも限らない。このように様々な意味で、投影法で得られる投影図と実際に描くべきとされる絵との間には多かれ少なかれ乖離があり、これを指摘して「透視図法を学ぶと絵が硬くなる」とか、「実用的ではない、不要だ」とか、「幾何学の遊戯に過ぎない」とか、果ては「間違っている」などといった主張も散見されます。

透視図法と実際の絵との間にどのような乖離があるのか知ることで、どのような時に使うべきなのか、どの程度頼りにすべきなのかをしる助けになるだろう。

その代わり、現実世界とどの程度乖離しているか、どの程度、には慎重な議論が必要。以下で詳細に議論する。

### 間違った透視図法の理解
正しい透視図法ではAではなくBですよ、という画像が、ひとり歩きして、透視図法に従ったAよりも透視図法に従わずに書いたBのほうが自然ですよ、という話に誤解されている場合がある。
正しい透視図法を学ぶべきだ。

### 画角が適切でない事による違和感
広すぎる画角を取っても、適切な視点から首を振るように鑑賞すれば違和感なく鑑賞できる。
しかし、画角が広い場合、視点から少しずれたときに違和感を感じやすい。
逆に、画角がある程度狭ければ、多少「本来の視点」からズレたところから鑑賞しても違和感のある絵にはなりにくい。

### モチーフ由来のズレ
作図法としての投影法は数学的な直線、垂直、平行、などを扱っているが、それらは現実に存在しない。
無限に真っ直ぐ続く道はない、手で並べた机や車列などはぴったり揃わない、など。

これはその通りで、現実のモチーフと透視図法で扱う数学的なモチーフの違いを区別しなければいけない。
古びた木造家屋はある程度歪んでいるはずなので、厳密に水平垂直なものとして透視図法を適用すると不自然で、敢えて歪ませた方が良い必要がある。

建築や都市を描く場合、意図的に誤差の量をコントロールすることで、時代や文明のレベル、土壌の硬さなどを表すことができる。モチーフをよく観察し、理解すること。
だからといって、全く役に立たないとするのは早計で、現実が多少歪んでいるとはいっても、ぐちゃぐちゃではないのだから、目安にはなる。
誤差が大きい場合は厳密な作図をする労力に見合わず、投影法を無視したり、崩したりするほうが効率的な場合もある。

ところで、これは「透視図法を崩している」のだろうか。
モチーフの垂直や平行が崩れているので、確かに透視図法における垂直や平行を描くための作図法の多くは適用できなくなる。
しかし、これは立体が歪んでいるだけであって、立体から平面への変換は透視投影そのまま（ガラス板をトレースするような操作）である。

中途半端に規則性が残っている状態が透視図法的にも目測で合わせるにしても、最も描くのが困難になる。
例えば。「ランダムな向きで置かれた机が、向きや位置は揃っていないものの、天板はすべて水平で、同じ比率の長方形である」という状態。
これはデジタルであればCGを使うか、上面図を描いてから自由変形ツールで作ってしまうのが一番手っ取り早い。

### デフォルメ由来のズレ
モチーフ由来のズレに似ているが、あちらが事実とインプット側の問題であるのに対し、こっちはアウトプット側の話題。
現実にある微妙な歪みを強調して水平垂直精度を崩すことが「味がある」「質感を表している」とされる場合がある。また、心理描写や世界観のために大きく歪んだモチーフを登場させたり、大きく歪ませて描く場合もある。このような場合は透視図法の労力に見合わない場合があるため、作図を簡略化したり目安程度にして崩したり、あるいは全く無視して目測でいい感じになるまで探る方が結果的に早い場合もある。

逆に、歪みを無視して数学的な図に近づけ、現実以上に精度を上げることが「安定感がある」「清潔感がある」などと好まれる場合もある。そのような場合には（よほど天才的な空間認識力がない限り）目測でその域に達するのは困難であるため、正確に作図することが逆に効率的になる。使いこなせるなら3D機能やCGで下図を作るのが最適だ。

### 本来の視点と異なる視点から鑑賞したときの個々のモチーフの歪み

対処法は、
・適切な視点から鑑賞させる
・画角を制限する
・魚眼パースによって緩和する　直線性が損なわれるので、適切な視点から見ても完全トレスにならない。
・個々のモチーフを注視点付近にあるかのように書く（嘘パースの一種）
これらは一長一短で完璧な答えはない。
視点が動いても正しい形に見えるとしたら、それはもう立体である。絵でできることではない

適切な視点は注視点の正面というだけでなく、投影面からの距離も定まっているのだった。したがって、視点から前後にズレる場合も、正確な像を再現したものにはならない。広角すぎると「画角が適切でない」で扱ったような違和感につながる。
しかし、画角が適切な範囲～望遠であれば、違和感として知覚されることはすくなく、むしろ注意を向けている対象の距離感を演出することができる。もちろん構図上の都合で画角を弄ることもある。

映像ではカメラの画角をコロコロ変えることがあり、これでは常に「本来の視点」から鑑賞することは不可能（画角が切り替わるたびに前後に移動しなければいけない）が、それでも違和感になることはなく、むしろ効果的に使われている。

## 影の作図
この項では、いくつかの不透明な物体と、一つの点光源または平行光源について、その光が直接届く範囲を考える。大きさのある光源についても簡単に述べるが、より複雑な光源や、定量的な明るさの見え方については別項で説明する。
直接光が届く範囲を「光面」、光が届かない場合を「かげ面」と呼ぶ。「かげ面」をひらがなで表記する理由は、影と陰を総称するためである。
面の法線が光源方向を向いていない場合、光は届かない。この影を「陰」またはshadeと呼ぶ。
面の法線が光源方向を向いている場合、光が届く場合と光が届かない場合がある。この影を「影」と呼ぶ。
原理は光線と面の交点の作図。光線は直線になる。
点光源の光線は一点を通る。平行光源では平行投影においては平行線、透視投影においては消失点に集結ないし平行線になる。

## 投影法以外の遠近法
投影法は各点の3次元座標を2次元座標に変換するものでした。投影法は様々なものがありましたが、投影面からの距離の情報を捨てることで、3次元の座標を2次元の座標に変換しているというのは共通です。つまり、投影法では本質的に遠近感を表現することができないのですを

ここまで扱ってきた透視投影は遠くに行くほど小さくなるという性質から、奥行きの情報を復元できるではないかと思うかもしれませんが、それはサイズの基準となるものが描かれている場合に限ります。透視投影であっても、近くにある小さな物体と、それの10倍遠くにあってサイズも10倍に拡大した物体とは全く同じ形に見えるため、区別できません。

このような奥行きの情報を絵に埋め込むことはできないのでしょうか？
投影法は座標の変換、つまりどの点がどこに描かれるかを表すもので、位置と形を決めるものでしたが、絵に含められる情報は座標だけではありません。色や塗り方などがそうです。これらを利用して失われた遠近の情報を与えることで、より立体的に見える絵を描くことができます。

### 線遠近法
投影法は（透視投影を含めて）本質的に奥行きの情報を持たないと述べましたが、透視投影は大きさが揃っている場合や同一平面上にある場合に遠近感を錯覚するのも事実なので、伝統的に遠近法の一種に位置づけられ、「線遠近法」と呼ばれることもあります。
この線遠近法、つまり透視図法から定量性を抜くと、大小遠近法や上下遠近法になります。

### 大小遠近法
透視図法では手前のものは大きく、遠くのものは小さく投影されますが、ここから定量の概念を抜くと、「大きく描くほど手前に見える」という素朴な遠近法の理解になります。これを「大小遠近法」と呼びましょう。

大小遠近法は定量的でない反面、透視図法と違って物体の形状を円や直線で定義できなくても適用することができます。
透視図法では近くて小さなものと遠くて大きなものは区別できないと述べましたが、この性質は大小遠近法でも変わりません。従って、大小遠近法は対象の大きさがおおよそ揃っているという事前知識があるときに効果が強くなる。
透視投影では一定の距離の差があるとき、近距離では見た目の大きさが大きく変化し、遠距離では見た目の大きさが少ししか変化しない。近距離～中距離では

### 上下遠近法
また、透視投影では（実は平行投影でも）、同一面上に物体が並んでいてその平面を見下ろしているとき、投影面上では奥にあるものほど上に、手前にあるものほど下に投影されます。

### 重なり遠近法
また、極めて自明なことですが、2つ以上の物体が同じ方向にあるとき（つまり視覚上重なっているとき）、もっとも手前にあるものだけが見えて、奥にあるものは隠されて見えなくなります。これを「重なり遠近法」と呼びましょう。
重なり遠近法は前後関係を表すのみで、距離の程度を表すのみです。
大小遠近法で区別できなかった、遠くにある大きなものなどを表すことができる
重なり遠近法を効果的に使うには重なっていることを認識しやすくする必要がある。

## 空気遠近法と強弱遠近法、色遠近法
### 空気遠近法
空気遠近法と呼ばれる表現があります。空気中の粒子や微細な水滴（霞）が光を散乱させることで、遠方の物体は霞んで見えます。これを描くことで奥行きを感じさせるのが空気遠近法です。
→ レイリー散乱とミー散乱、多重散乱
→ モナリザ
→ 指数近似
多重散乱を無視し、光が一定距離進行するごとに一定の割合である色に近づく、と考えることができ、その場合、光の強度は指数関数的に物体の色から霞の色≒空の色に漸近していく。
昼間の月のように、明部だけ見えることがある

### 強弱遠近法
コントラストが強いものは手前に、コントラストが弱いものは奥に見えるという認知上の傾向があります。これを利用したものが強弱遠近法です。
ここでいうコントラストとは、物体の輪郭における背景との対するコントラストと、物体内の模様や陰影に現れるコントラストの二種類が考えられます。
物理的に合理性を考えると色のついた気体が充満しているとか、ミー散乱を起こすような粒子が充満しているとかで説明付けることが可能ですが、何にせよ空気遠近法の派生と考えることができそうです。

### 色遠近法
前進色と後退色というのがあります。条件を揃えると波長の長い色は手前に、波長の短い色は奥に見えるという認知上の傾向があります、これを利用したものが色遠近法です。
この差が出る原因については十分な説明が見つかりませんでしたが、空気遠近法において波長の短い色がレイリー散乱によって横から割り込んでくることが多いから……という仮説を立てることができます。つまり、空気遠近法から定量性を抜いて、色相に関する部分だけを表したものと言えそうです。

## 影響遠近法
影を落とす、反射屈折するなど、ある物体が別の物体の影響を受ける場合、その受け方によって二つの物体の距離感を表現することができる。

## ピント遠近法とVR
→ 視点を大きさのない点として考えていたが、人間の瞳孔やカメラのレンズには一定の大きさがあり、レンズによって結像させている。
→ 十分に穴の小さいピンホールカメラを使うと、ほぼ透視投影の理論通りの像が得られる。
→ レンズによる結像は、適切な距離でしか結像しない。その距離をピント面と呼ぶ。ピント面からズレた場合、絞り形状でボケが発生する。これを再現することで遠近感を表すことができる。

→ 絞りの大きさとレンズの法則、レンズとスクリーンの距離から、このボケの大きさを計算できる。
→ 前ボケはカメラに近づくほど無限に大きくなる。後ボケは無限に遠くしてもある大きさに収束する。
→ したがって、ピント遠近法によって前後を区別できるのは超近距離～ピント面より少し遠くまでで、遠方と長遠方の差は区別が難しい。

→ ボケの形状、玉ボケの輪郭、口径食、ケラレ
→ ボケはガウスブラーがない。

→ ボケが十分に小さい距離の範囲のことを被写界深度（DoF)と呼び、イラスト技法としても一般的にはその名前で知られる。

→ アナログ技法においては前ボケが避けられ、最も近いモチーフにピントを合わせることが多い。アナログの画材では大半径をキレイにぼかすことが難しいからと考えられる。エアブラシを使えば可能かもしれない。

→ F値のスケールしなさとミニチュア表現

→ 人間の目が大きさ0の点ではないという意味では、両目があるというのもそう。これを利用したのが立体視やVR。

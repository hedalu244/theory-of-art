道具としての数学

美術に限らず、あらゆるものを理論化するにあたって、数学的な視点から物事を語ることは非常に有用です。数学は、世界を記述するための強力な道具であり、物理学や経済学などの分野で広く使われています。そのような視点を美術にも応用しようと考えています。

数学というと難しそうに聞こえるでしょうし、なぜ美術のために数学が必要なのかわからない、そんなのは机上の空論ではないか、と思うかもしれません。しかし、数学は物事を一般的に捉え、定量的な理解を得るための重要な道具なのです。むしろ、このテキストが数学を学ぶ/学びなおすモチベーションのひとつになってくれれば幸いです。

そうはいっても、まだ習っていない部分や、苦手な読者も少なからずいると思いますので、本題のほうでは数学についての知識がなくてもある程度理解できるように記述するように心がけます。

==

そして、数学と理論化は切っても切り離せない関係にあるため、まずはこの方法論に慣れ親しんでもらう必要があります。 具体的にどういうことなのか、例を挙げて説明していきます。

理論化とは一般化である

世界には無数の現象があります。例えば「昨日食べたリンゴは甘かった」とか「太郎君がテレビを見て笑っている」とかです。もうすこし美術に関連することで例えると、「リンゴを赤く塗ったらおいしそうに見えた」とか「ここの影を暗くするといい感じになった」とかです。

このような現象は無数にあって、それらを個別に覚えていくことは不可能だし、覚えたとしてもそれを応用するのは難しいものです。そこで、いくつかの事象に共通点を見出すことで、共通の法則やパターンを見つけ出すことができます。

たとえば「昨日食べたリンゴは甘かった」という現象と、「今日たべたリンゴも甘かった」という現象を知っていたとします。しかし、これを個別に覚えるのは効率が悪いです。昨日食べたリンゴAと、今日食べたリンゴBは別のものですが、どちらもリンゴではあるので、共通の性質を持っていると考えられます。これが「一般化」です。そして、共通の性質を見出すことができれば、「昨日食べたリンゴは甘かったし今日たべたリンゴも甘かったので、きっとリンゴとは甘いものなんだろうなぁ」と類推することができます。これは「帰納法」と呼ばれる推論です。

Caution
 「数学的帰納法」とは異なります。混同しないようにしてください。

そして、一般化ができると、予測ができるようになります。「リンゴとは甘いものなのだから、明日りんごを食べてもきっと甘いだろうなぁ」といった感じです。予測ができるとうれしいですね。甘いものが好きであれば、明日もリンゴを食べようという行動指針になります。絵で言えば場合においても、「どうすればかっこよくなるか」「どうすればリアルになるか」などが予測できれば、絵を描くときの指針になるわけです。これは大きなメリットです。

しかし、このような帰納法に基づく予測は、あくまで「きっとそうだろうなぁ」という程度のものであって、絶対に正しいとは限りません。例えば、昨日食べたリンゴが甘かったからといって、すべてのリンゴが甘いとは限らないし、明日食べるリンゴが甘いとも限りません。実際に甘くないリンゴがあった場合、それを「反例」と呼びます。反例があると、その一般化は間違っていることになります。だから、一般化や予測をする際には、できるだけ多くの事象を観察して、反例がないかどうかを確認することが重要になります。

帰納法と対立する概念として「演繹法」があります。演繹法は、いくつかの常に使える法則や、正しいと黙認した事実をもとに、それらを組み合わせて新しい事実を知る方法です。有名なのは三段論法で、「すべての人は死ぬ」「ソクラテスは人である」「だから、ソクラテスは死ぬ」というようなものです。演繹法は、前提が正しければ、必ず正しい結論が得られるという特徴があります。

数学は一般化に特化したツール

ばかばかしいほど簡単な例から始めましょう。

まず、右手に2つのコイン（一円玉にしましょうか）を握り、左手で3つのコインを握ってください。その後、両手を開いてすべてのコインを机の上に並べます。さて、コインは何枚になったでしょうか？　もちろん、答えは5ですね。もし、万が一、2+3が分からなかったとしても、実際にやってみて数えればわかります。

では次に、右手に二本の鉛筆を、左手に三本の鉛筆を握ってみてください。その後、両手の鉛筆を机の上に並べます。さて、鉛筆は何本になったでしょうか？　これも2+3=5なので5本になりますね。実際に数える必要があれば数えてみてください。

今度は、右手に二本の高級腕時計を、左手に三本の高級腕時計をもって、両手の腕時計を机の上に並べることを想像してみましょう。たぶん、これを手元でやるのは難しいですよね（高級腕時計を5つも持っている人はレアなはずです）。でも、もう十分ですね。実際にやってみなくても、答えは5本になるとわかります。

じつは、これが数学の力です。

コインと鉛筆、腕時計は全然違うものなのに同様に数えることができて、2とか3といった数字を割り当てることができる。これが「抽象化」です。

よく考えると、鉛筆と腕時計は形、重さ、価値などが全く異なるのに、2本の鉛筆と2つの腕時計はどちらも「2」として扱うことができます。また、鉛筆同士でも使いかけなら長さがまちまちだったり、1円玉同士でも製造年や傷などに注目すれば違いがありますが、「それぞれ個性のあるコインAとコインBとコインC」ではなく、「3つのコイン」として扱うことができます。数字に落とし込むとき、それぞれの個性についてはいったん無視しているのです。

そして、数字を足すときには、それがコインだったか鉛筆だったかに関わらず、2+3という式で表すことができる。これが「操作」です。実際にものを操作するとなると、手元に用意できないとか場合によっては重くて動かせないとかの問題が起きますが、数の操作は頭の中や紙の上、計算機の中で行うことができるため、非常に便利です。そして、実際に腕時計を用意しなくても結果がわかる。これが「予測」です。もっとも簡単な足し算ですら、実はこんなに高度なことをしていたのです。

特に大事なのは「予測できる」という点です。コインを合わせるという具体的な状況ではなく、2個のと3個を合わせると5個になる、という法則は、それが何であろうと成り立つはずの、一般的な法則だと考えられます。なので、実際に試すのが難しい状況でも結果が予測できたのです。これはうれしいですね。

この抽象化の力は強力です。2+3=5という一つの式さえ知っていれば、200人の群衆と300人の群衆を合わせると500人になる（100人の集団を1として、それを「数える」ことができる）とか、20cmの棒と30cmの棒をつなぎ合わせると50cmの棒になる（10cmごとに目盛りを書きこんで区切れば、目盛りと目盛りの間の数を「数える」ことができる）とか、幅広いことまで予測できるようになります。

このように、数学は、具体的なものを抽象化して、一般的な法則や関係性を見つけ出すための道具なのです。物理や経済などで数学を活用するのはすべてこの延長にあります。

Caution
 ここでは足し算を知らない人でもわかるような説明になっていますが、流石に、足し算、引き算、掛け算、割り算といった基本的な算数の内容は覚えておいてほしいです。
2+3=5 は帰納的だろうか、演繹的だろうか。

この説明だと、「2個と3個をあわせて数える操作」を何回か試してみて、何度やってもとも5個だったから、きっと2+3は5なんだろうなぁ、という帰納的な説明のように見えるかもしれません。では、2+3が5にならないような反例が存在するのでしょうか。もし反例が存在したら2+3=5が間違っているということになるのでしょうか。……これは少し語弊がありましたね。

実は、2+3=5を含め、数学的な事実はすべてが演繹によって証明されるものです。つまり、2+3=5は、論理的に導き出されるものであって、実際にコインを合わせてみて確認しなくても証明可能なのです。

演繹ということは前提があり、手順があります。具体的にどのような前提を置いて、どのような手順で2+3=5が導き出されるのか、ということは複雑なのですが簡易的に紹介します。

前提 1. 1のひとつ後ろの数を2と呼ぶ。 2. 2のひとつ後ろの数を3と呼ぶ。 3. 3のひとつ後ろの数を4と呼ぶ。 4. 4のひとつ後ろの数を5と呼ぶ。 5. x+1は、xのひとつ後ろの数である。 6. a+(bのひとつ後ろの数) は、(a+b)のひとつ後ろの数である。

手順 1. 3は2のひとつ後ろの数であるから、2+3は「2+(2のひとつうしろの数)」であり「(2+2)のひとつ後ろの数」である。 2. 2は1のひとつ後ろの数であるから、2+2は「2+(1のひとつうしろの数)」であり「(2+1)のひとつ後ろの数」である。 3. 2+1は、2のひとつ後ろの数であるから、「3」である。 4. 「(2+1)のひとつ後ろの数」は「3のひとつ後ろの数」であるから、「4」である。 5. 「(2+2)のひとつ後ろの数」は「4のひとつ後ろの数」であるから、「5」である。

前提の1～4は数の呼び方の問題なので、そう呼ぶことにしただけなので常に正しいです。5と6は足し算の定義のようなもので、丁寧に確認すると、ものを順番に数える操作と上手く対応していることが分かります。

誤差と近似

先ほど、20cmの棒と30cmの棒をつなぎ合わせると50cmの棒になるという例を出しました。しかし、実際に与えられた棒をメジャーなどで測って、一見20cmに見えたとしても、実際は20.01cmだったり、19.99cmだったりするかもしれません。。実際には、20cmピッタリの棒というのはなかなか難しいものなのです。このような時には2+3=5は使えないのでしょうか。

そんなことはありません。「だいたい20cm」の棒と「だいたい30cm」の棒をつなぎ合わせると「だいたい50cm」の棒になる、ということは言えるでしょう。これが分かるだけでも十分であることが多いです。もう少し踏み込んで考えてみると、以下のように考えています。

  1. 手元にある棒は20cmピッタリとは言えないが、だいたい20cmといえる。30cmの棒も同様。これが「近似」です。

  2. もし20cmピッタリの棒と30cmピッタリの棒が存在するとした場合、それをつないだら50cmになる（実際に用意できないものでも、「予測」できるんでしたね）。これは「モデル化」と呼ばれます。

  3. すると、手元にある棒をつなぎ合わせた結果もおそらく、だいたい50cmになるだろう。これも「予測」です。

Note
 近似はある意味で抽象化の一種とも言えるかもしれあせん。だいたい20cmの棒を20cmであるかのように扱うのは、鉛筆や1円玉を多少の差異を無視して「2」や「3」に落とし込んだことに少し似ています。

そんな雑な扱いをしていいの？　と思うのは自然なことです。

まとめ

「世界は数学でできている」というのは過言であると紹介しました。実際、現実世界は極めて複雑で、完全に正確な数値を得ることは難しいことが多いですが、それでも一定のモデル化と近似を繰り返すことで、なんとかそれらしい法則を見つけている、というのが実情です。うまい近似をすればいい感じの法則が得られるが、あまりに極端な近似を繰り返すと、まったく現実に即していない法則になってしまうこともあります。

Note
 それを揶揄したジョークとして、https://ja.wikipedia.org/wiki/%E7%90%83%E5%BD%A2%E3%81%AE%E7%89%9B[球形の牛] が有名です。

それでも数学を使って記述するのは、「予測」できるうれしさがなによりも大きいからです。 これは現実の多数の事象を個別に理解するのでは絶対に得られず、抽象化、法則化することで得られるメリットです。その抽象化のための強力なツールが数学です。だからこそ、人間は道具として数学を使っては世界を理解しているのです。

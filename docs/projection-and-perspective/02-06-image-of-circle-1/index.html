円の像について考えますが、厳密に扱うのは少々難しいので、このページでは簡易的に扱える範囲を紹介し、あとで厳密な観点から補足します。

まず、定義から確認しましょう。

定義（円）

平面πとπ上の点P、長さrがあったとき、平面π上で点Pから長さrの距離にある点の集合を円と呼ぶ またこのとき、Pを円の中心、rを円の半径、Pを通りπに垂直な直線を円の軸と呼ぶ。

円の軸というのは数学ではあまり使わない言葉ですが、ここでは、円の像を考えるときに便利な概念なので定義しておきます。円は回転体の一種です。

定義（回転体）

直線を軸として、その軸に対して回転対称な図形を回転体と呼ぶ。

Note
 本テキストで単に回転対称といった時には、任意の角度で回転させても重なることを指します。つまり、2回対称や3回対称ではなく、無限回対称のことを指します。

円だけでなく、円柱や円錐（直円錐）も回転体の一種です。現実への応用では、皿、瓶、ワイングラスなどの複雑な形も、ディティールを除けば回転体と考えることができます。取っ手のついたマグカップは回転体ではありませんが、取っ手を除いた部分だけで言えば回転体とみることができます。円を描く必要があるのは、ほとんどが回転体を描く場合です。

定理(回転体の像)

回転体の軸の像が視心を通るとき、像はその軸の像に対して線対称である。

回転体の軸をl、lの像をl’とする。 Eとlで定まる平面をαとすると、l’はα上にある 視心がl’上にあるため、視軸はα上にある。したがってαは投影面に垂直。 投影面と回転体はαに対して面対称なので、対称性により回転体の像はl’に対して線対称である。■

証明を読むとわかるとおり、これは回転体の軸が視心を通っている場合の対称性を利用した主張です。 しかし、これだけでは不便なので、「回転体の軸の像が十分に視心付近を通る場合は、回転体の像はその軸の像に対して線対称であると近似できる」と考えます。さらに極端に、以下のように言ってしまいます。

仮定

回転体の像は 常に その軸の像に対して線対称であると扱ってよい。

これは、厳密には数学的には間違った主張で、これに基づいて厳密な作図をしようと思うと矛盾が簡単に作れてしまいます。が、絵を描くうえでは、ほとんどの場合、投影面の視心付近を描くので、実用上大きな問題は起きません。なので、多くの人、というかほぼ全員がこの主張を信じています。

円の像はどのように考えられるでしょうか。卵型やまんじゅう型になってもおかしくないように思えますが、そうはなりません。

定理（円の像）

円の全体が像を持つとき、円の像は楕円になる。

Note
 楕円と言っても、円である場合もあることに注意して下さい。楕円でないことを

楕円というのは以下のような図形です。単に「歪んだ円」という意味ではありません。短軸に対してだけでなく、長軸に対しても対称であることに気を付けてください。

もし「円を斜めから見たら潰れるのだから当然だ」と思った人がいるとしたら、ちょっと待ってください。そんなに簡単な話ではありません。（まだ扱っていませんが）平行投影であれば単に図形を引き延ばしたり潰したりしていると考えることができるので当たり前かもしれませんが、今考えているのは透視図法です。透視図法において、平行線が平行にならず、正方形の像が不等辺四角形になることを考えると、これは極めて非自明な主張です。左右はともかく、前後、奥行き方向についても対称な形になるのは、実は不思議なことです。

にもかかわらず、 この主張は 数学的に正確に成り立ちます 。厳密な証明は後回しにして、ここでは直感的な理解を紹介します。

定義に基づくと、視点Eから円周上の各点Pに向かって半直線EPを伸ばしていき、投影面と交わる点が円の像です。これは見方を変えると、視点を頂点とする円錐を平面で切った断面を求めていると考えることができます。

Note
 ある平面図形を底面とし、平面上にない頂点について、頂点から平面図形のばす線分または半直線を集めた図形を錐体と呼びます。円錐とは底面が円の錐体です。

そして、 円錐を斜めの平面で切ると、楕円が得られる ことがよく知られています。つまり円錐の細い方か太い方か関わらず、対称な形になるのです。これは、透視図法における円の像がまんじゅう型や卵型にならず楕円になることと本質的に同じ非直感的な事実なので、これを理解できれば円の像が正確に楕円になることを理解したと言えそうです。この問題についての幾何的な証明については以下の動画が詳しいです。

「仮定」から、次の主張が示せます。数学的な正しさを求める場合は、軸の像が視心を通るにある場合、という条件を付けて理解してください。

定理（楕円の軸）

円Cの像が（円でない）楕円C’であるとき、Cの軸の像はC’の長軸または短軸と一致する。

円Cの軸をl、lの像をl’とする。 C’は円ではない楕円なので対称軸は長軸と短軸の2つしかない。 一方で、「仮定」 より、C’はl’に対して線対称である。 したがって、l’はC’の長軸か短軸のどちらかと一致する。■

Note
 似た言葉ですが、円の軸は円が存在する平面に対して垂直な直線であるのに対し、楕円の長軸や短軸は楕円が存在する平面上にある直線で、まったく違うものを指しています。

円の中心の像は、楕円の中心と一致しない。

円に外接する正方形とその像を考え、正方形の中心を作図するとわかります。円の輪郭だけを書けば良い場合には意識する必要はありませんが、中心に点を描かなければいけない場合には必要です。 また、同心円の像を描かなければいけない場面でも、これは意識する必要があります。

作図への応用

曲線なので定規とコンパスで作図することはできないが、 像の対称性を理解することは重要。 デジタルであれば、楕円ツールや線対称ツールを使うことで、容易に描画できる。 アナログでも、型紙を作る、長さを測る、コンパスを工夫して用いるなど、道具と方法を適切に選ぶことで、線対称を描くことができる。 フリーハンドで描く場合も、対称性を知っていると自分の絵の歪みに気付きやすい

実用上では、自分の描いている絵の中で回転体の対称性が意図せず対称性が大きく崩れていることに気付けないことや、正確に線対称に描けないこと、のほうが問題になることが多いです。

当然、回転体の像が線対称であると意識することで、歪みとして見えやすいです。

楕円の軸を見つけることは重要です。軸で4等分したそれぞれが合同であることを意識することで、フリーハンドでも精度の高い楕円を描くことができるからです。

周囲の対称性が崩れているときに誤りやすいので注意が必要です。例えば、マグカップの取っ手や、ビーカーの注ぎ口などがあった時に、それを通る線を長軸だと誤認することがよくあります。これらは面対称な図形の対称軸（正中線）ですが、回転体は回転対称なので、それらの要因によって像の形が変化することは無い。

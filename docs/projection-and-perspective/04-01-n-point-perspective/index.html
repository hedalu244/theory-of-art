直方体を描くための準備

ここからは、より実用的な作図法として、直方体や立方体の作図について考えていきます。これらはいずれも12本の辺で構成されていて、それらを平行な関係でグループにまとめると、4本ずつ、3グループに分類できます。異なるグループに属する辺は、互いに直交しています。なので、このような「互いに直交する3グループ」を便利に扱うために「直交系」という概念を定義します。

定義（直交系）

3つの直線 l,m,n があって、lとm,mとn、nとlが互いに直交しているとき、この(l,m,n)の組を「直交系」と呼ぶ。

そして、理想カメラに対する直交系の配置（理想カメラとの位置関係）を、以下のように分類します。

定義(1～3点透視図法)

(l,m,n)を直交系とする。理想カメラに対する直交系の配置を以下のように分類する。

  1. l,m,nのうち、1つが消失点を持ち、2つが投影面に平行であるような 配置 を、「1点透視図法」と呼ぶ。

  2. l,m,nのうち、2つが消失点を持ち、1つが投影面に平行であるような 配置 を、「2点透視図法」と呼ぶ。

  3. l,m,nのうち、3つとも消失点を持つような 配置 を、「3点透視図法」と呼ぶ。

Note
 本によってはこれとは違った定義を書いていることもありますが、ここではこのように定義した方が圧倒的に「話が簡単になる」ので、この定義を設定しています。

極めてよくある誤解

1点透視図法、2点透視図法、3点透視図法という言葉から遠近法を習ったことがある人が多いと思います。しかし、透視図法に関してこれほど誤解されている単語もありません。これは本当に誤解を招きやすい名称が定着してしまっていて、残念極まりないです。例を以下に挙げます。いずれかに該当する誤解をしていた場合は、この機会に正しい理解に修正してください。

「～図法」に由来する誤解

「～図法」というネーミングであることで、「1点透視図法」「2点透視図法」「3点透視図法」が、それぞれが別の「図法」である、つまり全く異なるアプローチであると勘違いしてしまうことがあります。実際は、上に定義したように「カメラと直交系の配置」についての分類です。1～3点透視図法は直交系との位置関係が違うだけで、どれも同じ透視図法で、同じ「理想カメラ」によって得られる像です。つまり、これらはすべて「視点から半直線を伸ばして投影面との交点を求める」という一つの統一規則によって作られる像なのです。。

従って、これらが「互換性がない」わけではありません。向きの異なる複数の直交系が登場するような複雑な状況では（例えば向きの異なる複数の直方体が存在するなど）、一定の条件を守る限り、iつの投影面の中に1点透視と2点透視図法と3点透視が同時に共存することもあるのです。

Note
 一方、平行投影に分類される等角図法や、キャビネット図、非球面投影で紹介する平射魚眼図法などは、透視図法とは異なる投影法なので、一般化して説明することができませんし、普通は一つの画面に収めることもありません。一つの画面に異なる投影法を混在させると、一貫性がないように見えて、違和感の原因となることがあります。

「1点」「2点」「3点」に由来する誤解

これらが一つの絵に使用する消失点の 総数 を規定しているという誤解もよくあります。すでに確認した通り、消失点は直線の「方向」と対応づいているのでした。多数の方向の直線が登場するような状況では、それだけ多くの消失点が登場します。実際、本テキストで扱う作図法では、3点透視図法でも必要に応じて6つ以上の消失点を利用します。

実際に描くような複雑な状況では、画面上に無数の消失点がある場合もあります。しかし、画面上で3つの消失点を使ったから3点だとか、5つの消失点があるから5点だとかいう数え方をしているわけではありません。しかし、 互いに直交する3直線の組み合わせそれぞれについて、そのうち、いくつが消失点を持つか、を数えているのです。

さらにひどい誤解をされると、「3点透視図法を使ったらすべてをその3つの消失点で 描かないといけない」と考えてしまう人もいます。3つの消失点を一度決めたらすべてをその3方向に「揃えて描かないといけない」、という誤解です。そのように誤解すると、すべての線が平行か垂直になってしまい、不自然なことになります。

平行な線であれば消失点は揃いますが、わずかにでも方向が違えば消失点も違う ので、新しい方向を登場させるたびに新しい消失点を設定してよいのです。別に、3点透視図法を使ったからと言って4つ以上の方向を描いてはいけない、4つ以上の消失点を使ってはいけないわけではありません。

作風によっては意図的に歪んだ建築物を描く場合があります。「建築物のゆがみを表現するために、消失点を意図的にずらす」というテクニックを、「消失円」や「消失面」などと銘打って紹介している例があります。これは結果的には自然な絵が得られるので悪くはないのですが、本質的には理解としては少々怪しいです。対象上の直線が厳密に平行でないからそれぞれが異なる消失点を持っているだけで、一つの消失点が広がりを持っていると考えるのは誤解を孕みやすいと思われます。

水平や上下と関連しているという誤解

何点透視図法を使うべきかが、水平や上下、つまり重力方向と関連している、という誤解があります。「1点透視図法は真横を見ている」「1点透視図法や2点透視図法の消失点は地平線上にある」「見上げたり見下ろしたりすると3点透視図法になる」などという言及がいたるところで見受けられます。ここで使われている「真横」「地平線」「見上げ/見下ろし」はすべて重力方向によって決まる言葉ですが、重力方向と透視図法の分類は全く関係ないことに注意してください。透視図法の分類は、あくまでも「カメラと直交系の配置」によって決まるものであって、重力方向とは無関係です。

現実世界には、地面に置かれた箱や建築物のように「直交系があって、そのうちの一つが 鉛直方向と一致している」ような状況が多いので、重力方向との関連を見出してしまうのも無理がないことですが、重力ととこの「1～3点透視図法」の分類は全く関係ないことに注意してください。このように理解してしまうと、「理想カメラの対称性」で述べた、カメラの回転対称性が損なわれてしまいます。つまり、視軸を中心にカメラを回しても像の形は変化しないので、重力方向で区別する意味がないのです。

現実世界で重力と関係ない反例として、例えば「カメラが水平でも傾斜した箱は3点透視になる場合がある」「ビルを真上に見上げる方向にカメラを置くと1点透視になる」「通りの正面から見上げる方向にカメラを置くと2点透視になる」などが挙げられます。これらをいちいち区別していくと無数の場合分けが必要になるので、重力とは無関係に分類を定義します。

4点、5点に拡張されるという誤解

巷には、直線を曲げて描くことで4つ目や5つ目の消失点が作れる、といって、それを「4点透視図法」や「5点透視図法」などと紹介している情報源があります。しかし、すでに確認したように、透視図法においては 直線の像が曲がることはないので、「4点 透視図法」と名付けるのは不適切です。直線を曲げて描くような投影法は非平面投影として扱いますが、これらは透視図法を拡張したもの、透視図法の延長にあるものではありません。

直方体と立方体

次頁から具体的に、1点透視図法、2点透視図法、3点透視図法において、直方体や立方体をどのように描くことができるかを説明していきます。 直方体は、3組の平行な辺を持つ立体で、立方体は、すべての辺が同じ長さの直方体です。つまり、立方体は長さを揃える必要があるという点で、直方体よりも本質的に難しいものとなっています。直方体は1～3つの消失点を定めることができれば 描けたも同然です。一方で立方体は、それに加えてどのように長さが同じことを保証するかという問題が付きまといます。

楕円の作図法

その1、その2では、円の像の性質について厳密な観点から議論しました。

このページでは、実用に即した楕円の作図法について扱います。厳密さを欠いた議論にはなりますが、見落としやすい注意点が無数にあるので、それらをしっかり理解し運用できるようになることの方が重要です。

重大な「仮定」

このページでは以下の3つを前提として、円の像を実用的に描く上での注意点を考えていきます。

「仮定」 - 円の像は楕円である。 - 回転体の像は、軸の像に対して線対称である。 - 円の軸の像は楕円の短軸に一致する。

これらはいずれも例外があるものの、、絵を描く人の間で広く信じられているものです。視心付近において、大きすぎない円を描く限りにおいては、「近似」として成り立つと考えられるものです。これらがどこまで正しく、どこが厳密には間違っていて、どのような場合に例外が生まれるのかは、前のページを参照してください。

この仮定を置く妥当性

「その1」「その2」を読んできた先に読んできた方は、この前提がどこまでが正しく、どこから間違っていて、どのような反例が作れるのかを説明できるでしょう。

この「前提」は、標準画角で絵を描く限りでは十分正確ですが、画角を広げていくとその限りではありません。これから紹介する方法はすべてこの前提に成り立っているため、広い画角では、「数学的に正しい」円の像との誤差が無視できなくなっていきます。

しかしこの「前提」が絵を描く人の間で広く信じられているのも事実です。（稀に、「楕円である」から信じていない人もいます。が、「その1」「その2」で出したような反例はほとんど知られていません）。

特に、長年この方法で絵を描いてきた人は、これを理由に、しばしば「3DCGは間違っている」や「広角レンズが歪んでいる」などと批判的に言うことすらあります。3DCGや（十分に高精度に作られた）レンズは理想カメラに近い挙動をするので、厳密に正しい円の像を描いてくれているのですが、手書きの楕円を描き慣れた人や見慣れた人からすると、逆に違和感の原因になることすらあるわけです。

そのような厳密さを手書きの絵やイラストに取り入れるのは、手間がかかる上にメリットが少ないです。この「前提」を取り入れることで、大幅に理解しやすくなり、作図も楽になります。そこで、いったんこの「前提」を認めるのは、厳密ではないにせよ、十分合理的だと考えられます。

それよりも、この「前提」を認めたとしても見落としやすい注意点が無数にあるので、それらをしっかり理解し運用できるようになることの方が重要です。

回転軸を決める

楕円を描く以前に、回転体について考えます。円は主に回転体の像の一部として現れますし、円自体が回転体でもあります。

像が線対称になるように描くのは比較的簡単です。デジタルであれば線対称ツールを使うことで描画できますし、アナログでも、型紙を作る、長さを測る、コンパスを工夫して用いるなどがあります。いずれの方法にしても対称軸が定まっていないと使えません。

「仮定」に基づくと回転体は線対称に描く必要があります。そのためにはまず対称軸＝回転軸を設定します。しかし、ここで失敗する人が非常に多いです。

回転体の回転対称性を忘れない

回転体は回転対称なので、向き（座標系の取り方に）よって像の形が変化することはありません。マグカップの取っ手や、ビーカーの注ぎ口など対称性を崩す要因がついていた時に、それらを通る線が対称軸に関与していると誤認することがよくあります。これらは面対称な図形の対称軸（正中線）ですが、関係ありません。以下のように回転していても関係ありません。

カメラの回転対称性を忘れない

カメラの回転対称性により、画面に対してどのような向きに軸が存在していても、その軸が回転軸であり回転体の対称軸です。

立方体の各面に楕円を描きこむ練習をすると覚えることができるでしょう。

軸が画面に対して傾いている場合、対称軸が鉛直になるように画面を回転させると描きやすくなります。（人間は自分に対して左右の線対称を確認することが、上下や斜めの対象を判定するより得意であるようです）。

対称性から逆算する

写真模写やデッサンなど現物を観察して描く場合にも、軸が分かっていると有利です。

回転軸に平行な直線が見えないときに使える方法が、対称性から逆算する

しかし、そのような場合でも、自分で軸の向きを設定することができないので、見えているものから回転軸を探す必要があります。

楕円の軸を探す

楕円の軸の方向とその長さを決めることができれば、楕円は一意に定まります。デジタルであれば、軸が分かれば楕円ツールを使うことができます。アナログでフリーハンドであったとしても、軸を基準に対称性を意識することが重要です。

長さについてはまだ扱えないので「一点透視図法」で扱います。

楕円の長軸については、必ず 短軸＝回転軸を決めてから、それに垂直になるように長軸を取ります。長軸を先に定ようとして、なんとなく「長そう」な方向を長軸にしてしまうのがよくある失敗です。

原則は次の手順です

  1. 円の軸の像を描く。これが仮定(3)により、楕円の短軸と一致する。

  2. 直線上で短軸の位置と長さを決める。

  3. 短軸に垂直2等分線を引いて、長軸とする。

  4. 長軸と短軸それぞれに対称になるように楕円を描く。

②枠を書いてからフリーハンド

私のおすすめの方法です。これは技能がなくとも、知識と時間を使えば必ず描ける方法です。時間をかけて正確に描きこんでいくデッサンなどに適しています。

楕円を描く際には、必ず 長軸と短軸を決めるところから初めます。まず、楕円の中心O、長軸の両端AとB、短軸の両端CとDを作図します。これらをどのような順で作図していくかは場合によりけりです（ABを二等分してOを得る場合も、AOを延長してBを得る場合もあるでしょう）が、最終的に OAとOB、OCとODの長さが等しいこと、ABとCDが直交していることを確認してください。そうなっていないと、楕円にはなりません。

③軸だけ描いてからフリーハンド

熟練した人は、勢いよくフリーハンドで描くこともできます。建築家やプロダクトデザイナーは短時間のスケッチで多数の楕円を描く必要があるため、この方法を好む傾向があります。

フリーハンドで描く場合も、まず長軸と短軸は決めておきましょう。そこに何度か空中で楕円を描きながら狙いを定め、イメージができたら、勢いよく描いてみてください。

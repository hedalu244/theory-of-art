== クイズ
[quiz]
--
色の三原色とは何色でしょうか？

* [ ] 赤・黄・青
* [*] シアン・マゼンタ・イエロー
* [ ] 赤・緑・黄

減法混色（理想的なインクや透明な絵の具など）に現れる色の三原色はのシアン・マゼンタ・イエローです。加法混色（光）の赤・緑・青と混同しないように注意してください。
--

[quiz]
--
ルネサンス期を代表する画家は誰でしょうか？

* [ ] ピカソ
* [ ] モネ
* [*] レオナルド・ダ・ヴィンチ
* [ ] ゴッホ

レオナルド・ダ・ヴィンチはルネサンス期（14〜16世紀）を代表する画家です。ピカソは20世紀、モネとゴッホは19世紀の画家です。
--

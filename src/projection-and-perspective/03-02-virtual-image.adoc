== 臨界面より後ろの像

点Pの像は、視点をEとすると半直線EPと投影面の交点でした。なので、点の像は臨界面より前にある場合のみ定義できるのでしたね。しかし、これが原因で場合分けが厄介になっている場面がたくさんあります。

そこで、便宜上、以下の概念を定義しておきます。

[.definition]
.定義（虚像）
--
視点をEとする。
点Pに対して、Pの像が存在しないとき、直線EPと投影面の交点があれば、それを虚像と呼ぶ。
図形Sに対して、S上の点の虚像をすべて集めた図形をSの虚像と呼ぶ。
--

これは要するに、視点Eから点Pと正反対方向に半直線を伸ばしたときに、投影面と交わったところを「虚像」と呼ぼう、と言っています。点Pの虚像をpとすると、Pとpは視点Eを挟んでちょうど180度反対の方向にあります。そのような虚像は点Pが臨界面より後ろにあるときに存在します。

虚像は「ガラス板になぞる方法」で言えば見えるわけがありません。人間は前しか見えないし、もし（複眼とかで）後ろが見えたとしても、真反対方向にあるものを「重なっている」といって投影面になぞるのは無理があります。しかし、幾何学的には、半直線より直線のほうが圧倒的に扱いやすいので、こういうものを考えます。

== モチベーションとのつながり

なぜこんなものを定義したかと言えば、臨界面より前にあるか後ろにあるかで場合分けしたくないからです。なので、 *このセクションに限っては* 断りなく「像」と言ったら基本的に虚像も含むと考えてください。従来の像であることを強調して「実像」と呼ぶことにします。

== 共線の保存

3つ（以上）の点が同一直線にあることを共線であると言います。透視図法の前後で、共線の関係が保たれます。

[.theorem]
.定理（共線の保存）
--
空間中の点A,B,Cが同一直線上にあって、それらが像a,b,cを持つとき、a,b,cは同一直線上にある。
--

[.proof]
.証明
--
視点をEとする。

点E,A,Bから定まる平面をαとする。 +
仮定より、ABCが同一直線上なのでCはα上にある。 +
像の定義より、EAaは同一直線上なのでaもα上にある。同様に、b,cもα上にある。 +
また、αは投影面と平行ではない（∵投影面上にないEを含んでいて、投影面との共有点abcも持っている）。
abcはαと投影面の共通部分上にあるので、同一直線上にある。 +
--

[.theorem]
.定理（直線上の図形の像）
--
図形Sが直線の一部（線分、半直線など）であるとき、Sの像も直線の一部である。
--
[.proof]
.証明
--
Sのうち像を持つ点が1点、2点以下であるときは自明なので、Sが3点以上を含むときに示す。 +
S上の2点をA,Bとし、それらの像をa,bとする。 +
S上の任意の点Cについて、A,B,Cは同一直線上にあるので、Cが像を持てば、定理（共線の保存）より、a,b,cも同一直線上にある。 +
従って、Sの像はa,bを含む直線の一部である。 +
--

これは透視図法において、直線や線分などの像が決して曲がらないことを示します。実在のカメラにおいては、魚眼レンズのように歪みのあるレンズの影響で直線が曲がることがあり、それを再現するような絵を描くこともありますが、透視図法に従う限り、そうはならないことが言えます。

== 共線の保存の逆

投影は次元を落とす変換なので、共線の保存の逆は成り立ちません。つまり、像が同一直線上にあっても、元の点が同一直線上にあるとは限りません。

点A,B,Cが同一直線上になくても、点A,B,Cを含む平面が直線に「縮退」することがあるからです

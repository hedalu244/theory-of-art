== 共線の保存

まず練習として、以下の定理を示しておきましょう。

[.theorem]
.定理（共線の保存）
--
空間中の点A,B,Cが同一直線上にあるとき、a,b,cは同一直線上にある。
--

[.proof]
.証明
--
視点をEとする。

点E,A,Bから定まる平面をαとする。 +
仮定より、ABCが同一直線上なのでCはα上にある。 +
像の定義より、EAaは同一直線上なのでaもα上にある。同様に、b,cもα上にある。 +
また、αは投影面と平行ではない（∵投影面上にないEを含んでいて、投影面との共有点abcも持っている）。
abcはαと投影面の共通部分上にあるので、同一直線上にある。 +
--

この定義は像が虚像になる場合や無限遠点になる場合を含めれば、A,B,Cが臨界面より後ろにあるときや、臨界面上にあるとき、無限遠点である場合にも同様になり立ちます。

== 「正確な形」とは何か？

形を正確に描写することは重要でしょうか。形が「正確に」描けている絵は、美術において「客観的」「冷静」などと評されることがあります。逆にデフォルメを効かせた絵は「感覚的」とか「勢いがある」とか評されることがあります。伝統的なリアリズムにおいては、前者はポジティブな評価で後者はネガティブな評価とされることが多いように思いますが、写真の登場以降は作風次第でどちらもポジティブな評価として受け入れられるようになっています。

しかし、ここでは「客観的」で「正確な」形に絞って議論を進めます。

とはいっても、そもそも、「正確な形」というのは主観や感性の介入なしに定義できるのでしょうか。写実的なデッサンを習うと、「見えたまま描け」といわれることがありますが、「見えたまま」というのは万人に共通なのでしょうか。

例えば、画家が人物モデルを雇って絵を描いたとします。画家は「何度も見比べながら描いたので正しい」と思っていますが、それを見たある人は、「もっと丸い気がする」と言いました。別の人は「もっと鼻が高い気がする」とか言うかもしれませんし、モデル本人が見たら「私はもっと美形なはずだ」とか言うかもしれません。さて、このとき、誰が言っていることが正解か、判別することはできるのでしょうか。

== 「見えたまま描く」の語弊

写実的なデッサンを習うと、「見えたまま描け」といわれることがありますが、これは *誤解しやすい言葉* です。

絵というのを「モチーフ→視点→脳→手→絵」というイメージで考えていると、「見えたまま」というのは、眼球に投影された像や脳内に入ってきた像「視野」をできるだけそのまま、歪みや主観が入らないように、をそのまま出力する必要があると思い込みんでしまいます。

しかし、「視野」がどのような形なのか、どのように人間が画像を処理しているかは単純ではありません。網膜の形がどうなっているだとか、脳内の処理がどうなっているだとか、検証が難しいことを考えてしまいます。

「見えたまま」というのはそういうことではありません。むしろ、「*同様に見えるものを描く*」と考えたほうがよいです。つまり、「モチーフ→視点→脳」と「絵→視点→脳」を比較して、両者を近づけることを目標とするのです。

そして、このとき、視点から脳にかけての処理は、モチーフを見ているときでも絵を見ているときでも共通のはずです。仮に、そこで何らかの複雑な変換や変形が行われていたとしても、それはモチーフだけでなく絵に対しても作用する変換です。その変換が行われた後のものを描いてしまうと、鑑賞者は二重に変換がかかった状態を見ることになってしまいます。

結局、リアリズムにおいては、視点から先の光学的な現象に関してモチーフと同じになるようにすることだけ注目すればよいのです。なので「視野とは何か」に関しては深く考える必要はありません。

しかし、どうすれば「同様に見えるものを描く」ことができるのでしょうか。

== 「なぞる」方法

ここで「同様に見えるもの」を描くための、ある意味で最も確実な方法を提案します。

まず、透明なガラス板を自分と対象の間に固定します。そして特定の場所に視点を固定して、見えた対象の形をそのまま、ガラス板上にペンで「なぞる」ようにして形を描くのです。

そんなにうまくいくはずがない、と思う人もいるでしょう。ここで、二つのコツがあります。まず、片眼で見ること。もう一つは目の位置が絶対に動かないようにすることです。特に後者は大事で、単に同じ場所に立つ、同じ椅子に座るだけでは体がブレてしまうので、固定したのぞき穴から覗くとか、顎を机に置くとか、何らかの方法で目の位置を完璧に固定する必要があります。この二つを守って、ある程度の時間と忍耐力を費やせば、きっと見えた形にぴったり重なるようになぞることができるでしょう。

== 「重なる」と「再現」

さて、先ほどの方法を用いて、どうにか頑張ってガラス板上でペンを動かしつづけたことで、その固定した視点から見ると完璧に重なって見える絵が *描けたとします*。

これは、「同様に見えるもの」を描くためのかなり確実な方法です。平面の形同士が同じかどうかを確かめるには、紙を重ねた時にぴったり重なれば全く同じ形をしていると確認できるでしょうし、トレーシングペーパーやカーボン紙などを使ってなぞればそのような形を得ることができます。この方法も同様に、「なぞる」ことによって「重ねれば重なる」形を得ています。これをもって「同様に見える」とするのは強い納得感があると思います。

また、この方法は「なぞる」という極めて単純な作業によって成り立っています。ここには画家の主観も介在しないし、「見比べる」とか「目測で測る」といった技術も必要ありません。誰がやっても（どのような程度仔細に書き込むかなどの差異は除いて、あくまで「形」だけを考えれば）ほぼ同じ結果になるという点でいえば、極めて「客観的」とも言えそうです。

そして、この方法はある一つの大きなメリットがあります。それは形を「再現」することができる、ということです。どういうことでしょうか。

ガラス板上に完璧な形をなぞった後、その形に従っていい感じにリアルな色を塗って、その後モチーフを取り除きます。そこに友達を呼んできて、描いた時と同じ視点から片目で、完成した絵を見てもらいます。すると、友達は、まるで対象がそこにあるかのように（少なくとも形については全く同じ形を）見ることができるでしょう。もし人間が片目では奥行きを区別できず、重なるかだけを判定できるとしたら、誇張した言い方をすれば *本物と区別できない* 絵が出来上がるわけです。これが「再現」です。これは、「同様に見える」であると同時に、遠近法の目的であった「立体感を錯覚させる」に十分に近いものと言えるでしょう。

== 「歪み」

一方で、デメリットもあります。視点を固定して描いた分、*鑑賞者の視点が変わると全く違う形に見えてしまうのです*。

特に、ガラス板の外周部では（正確に言えば視点から遠くなるほど）、外側に引き伸ばされるように歪んで見えることが知られています。

しかし、これはある意味当たり前ともいえます。視点を動かしても正確に見えるというのは、もはや絵ではなく立体物でないとあり得ない話です。どのような方法を取っても、どこかに必ず歪みが出ます。

ただし、ここで「歪んで見える」というのは、描いたのと別の位置から見ているときの話です。*描いたときの視点から見れば*、どんなにガラス板が大きくても、もっと言えばガラス板が画家とモチーフの間に斜めに配置されていたとしても、歪んで見えることはありません。ある視点から完璧に重なるように描けば、その視点からは完璧に重なって見えるし、完璧に形が再現する、つまりそのように描いたらそうなるという当然の話なのですが、ここは要注意です。

また、このプロセスで「顔の向き」や「眼球の向き」については一切言及していないことに注意してください。「ガラス板」の向きも決めていません。ガラス板の外周部を見るとき、視線の向きに対してガラス板は斜めになっていますが、それでも歪んで見えることはありません。あくまでも「視点の位置」が動いていなければ、形はぴったり重なるのです。

== 現物は必要か

ところで、この方法の別のデメリットとして、「現物とガラス板を用意しないといけない」「視点や対象、ガラス板が動いてしまうと形をなぞることができない」などといった問題もあります。確かに、ガラス板を用意するのは大掛かりですし、想像上のものや高価なもの、動き回るものを描くのに使えないとなると、これは致命的です。

これらを回避するために、実際にこの「ガラス板になぞる」を行わずとも、それと行ったのと同じ形を予想し、描く方法があれば得る方法があればいいなぁ、と思うのは自然なことです。そのために幾何学が強力な道具となります。

これは現実に存在する複雑な物体を描くことを一旦諦めて幾何学的な形に限定することで、思考と計算、紙上の作図によって、正確になぞった形を得ることが可能となります。（そこから現実に存在する形への応用については、link:../index/[index] で述べたとおりです。

次はページからは、これを幾何学の問題に落とし込むために、「ガラス板になぞる方法」を幾何学的に表していきます。

== 「正確な形」は定義次第

ただし、ここまで話してきたはあくまでも「*ある意味で正しいと呼べそう* な形」を得る方法の *ひとつ* に過ぎないことを忘れないでください。

正確といっても、まったく別の方法（例えば、曲面に写し取ったらどうなるかとか、現物を定規で測って云云とか）を採用すればまったく別の形になるでしょう。「正確な形」は定義次第でどうとでも変わります。

しかし、とりあえずはこの方法に立って話を進めます。
